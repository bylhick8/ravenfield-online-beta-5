# Ravenfield Beta 5 — WebGL Port

Ravenfield Beta 5 in the browser (Unity WebGL, asm.js).

**Play:** open `index.html` — main launcher. `game.html` — game directly.

Direct links:
- `game.html#level=Island`
- `game.html#level=Dustbowl`

**Controls:** F2 — optimization toggle (ON by default). FPS counter top-left.

- Original game: Ravenfield by SteelRaven7 (free Beta 5, itch.io)
- WebGL port: **bylhick=roman**
- Unofficial fan build. Please support the original developer on Steam.
